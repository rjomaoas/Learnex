# 📱 LEARNEX – Flutter Mobile Application

**Learnex** is a Flutter-based mobile application structured for scalability, maintainability, and clean separation of concerns.  
This project follows Flutter best practices using modular folders for screens, components, services, and models.

---

## 📌 Project Description

Learnex is a cross-platform mobile application built using **Flutter**, designed to support Android (and iOS-ready).  
The project uses a clean folder structure that allows easy feature expansion, API integration, and UI reuse.

---

## 🛠️ Tech Stack

- **Flutter (Dart)**
- **Material Design**
- **Android SDK**
- **VS Code / Android Studio**
